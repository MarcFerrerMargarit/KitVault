# KitVault social foundation

The source of truth for every KitVault social campaign. Read these before writing anything,
in this order:

1. `brand-profile.md`: who KitVault is, audience summary, proof, CTAs, guardrails, AI policy,
   visual identity
2. `voice.md`: how KitVault writes (fingerprint, lexicon, tone map, do/don't rewrites)
3. `audience.md`: segments, jobs-to-be-done, objections, language bank
4. `positioning.md`: positioning statement, alternatives, messaging hierarchy, **claims
   register**
5. `content-pillars.md`: the 4 themes and the mix
6. `social-strategy.md`: objective, channel roles, cadence, UTMs, phasing
7. `platforms/instagram.md`, `platforms/tiktok.md`, `platforms/x.md`, `platforms/linkedin.md`

Campaign assets go in `marketing/social/{campaign-slug}/{platform}/`.

**Update these files when:** sharing ships, payments open, a native app ships, real
metrics/testimonials exist, or quarterly. Bump the version in each file's header comment.
