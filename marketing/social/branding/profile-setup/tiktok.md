# TikTok — profile setup (secondary channel)
<!-- status: DRAFT, awaiting approval · updated: 2026-09-25 · reads: foundation/platforms/tiktok.md -->

**Audience:** football shirt collectors, mostly cold (people who don't follow us yet), arriving
from the For You feed or from search. **Job of the profile:** make clear, instantly, that
KitVault is an **app for your collection**, not a shop. An account named "Kitvault" already
sells shirts on TikTok (see `usernames.md`).

## Copy-paste values

| Field | Value |
|---|---|
| Account type | **Business account** (free). It's needed for the website link and analytics. Audio is limited to the Commercial Music Library, which the strategy already requires |
| Name (display name, ≤30) | `KitVault · Football Shirts` |
| Username | `kitvaultdev` (fallbacks: `getkitvault`, `kitvaultapp`, `kitvault.dev`) |
| Bio (≤80) | see below |
| Website | `https://kitvault.dev/?utm_source=tiktok&utm_medium=social&utm_campaign=profile` |
| Business category | The closest to an app or software (for example "Software & Apps"). Don't pick "Clothing" or anything retail: that's what the other "Kitvault" is |
| Email (business contact) | **leave blank** (no public address; see `links.md`) |
| Pronouns | leave blank |
| Instagram / YouTube links | Link Instagram (`kitvaultdev`) once it exists. YouTube: leave blank |
| Profile photo | `branding/profile-images/final/tiktok-profile.png` (1024², full-bleed Vault Tile) |

### Name
```
KitVault · Football Shirts
```
The name is searchable on TikTok. "Football Shirts" is the search term collectors use.

### Bio (≤80 characters)
```
Collection app: photograph a football shirt, AI identifies it. Try it for free ↓
```
That is exactly 80 characters. If the app counts the arrow differently and rejects it, use:
```
Photograph a football shirt. AI tells you what it is. Try it for free ↓
```
The first version opens with "Collection app" to separate KitVault from the shirt-selling
"Kitvault" account. Use it if the character count allows.

### Long description
Not supported on TikTok.

## CTA
**Try it for free** (bio + link). In videos: the end card says `Try it for free · kitvault.dev`,
and the caption says "link in bio". The pinned comment asks for the next shirt to test.

## Keywords (captions, on-screen text, spoken text)
football shirt · football shirt collection · what season is this shirt · football shirt
identification · retro football shirts · football kit · shirt collection app

Hashtags (3–4 per video): `#footballshirts #footballshirtcollection #retrofootballshirts` + a club
tag. Never `#fyp`, and **never `#kitvault`** (that tag mixes our feed with the shirt seller's).

## Pinned videos (3 slots)
| Slot | Video | Why |
|---|---|---|
| 1 | A **native TikTok edit of launch Reel 01**: same footage, faster cuts, TikTok-native text, no Instagram watermark | The explainer: what KitVault is, in ≤20s |
| 2 | The first **"Can KitVault ID this?"** video | The series people come back for |
| 3 | The first **season-ID explainer** ("how to tell what season a football shirt is") | It's the search lane, and it keeps getting found |

**What the first pinned video must communicate:** a real shirt → photographed → the real app fills
in team, season, version and maker with a confidence % → you check it → it's in your vault. Free
to try. Hands, shirt and screen are enough, so no face or AI voice is needed.

## Profile image
`branding/profile-images/final/tiktok-profile.png`. TikTok is dark-UI first, and the green disc
stands out there.

## Banner / cover
TikTok has no banner. Set a **video cover** for every pinned video: #0d0d0f, Oswald uppercase,
the question or the shirt in the centre third (the grid crops the top and bottom).

## Other fields to complete
- [ ] Switch to a Business account (Settings → Account → Switch to Business Account) before
      adding the website.
- [ ] Create playlists once there are 3+ videos each: `Can KitVault ID this?` ·
      `How to date a shirt`.

## Leave blank on purpose
Email · phone · pronouns · YouTube · shop/showcase features (KitVault sells nothing on TikTok) ·
any paid promote/verification feature.
